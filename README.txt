PORTFOLIO DE CLEMENTE RAMOS — HTML + CSS + JavaScript

ARCHIVOS
- index.html: página principal, presentación, timeline, áreas de interés y contacto.
- acerca.html: página independiente "Acerca de mí".
- proyectos.html: página de proyectos documentados.
- estilos.css: estilos compartidos y diseño responsive.
- script.js: menú móvil.
- multimedia/imagenes y multimedia/videos: carpetas para tus propios recursos.

ANTES DE PUBLICAR
1. Abre la carpeta en Visual Studio Code.
2. En index.html, cambia TU_CORREO@ejemplo.com por tu correo real.
3. Cambia +34 000 000 000 por tu teléfono real.
4. Actualiza los enlaces y textos de LinkedIn y GitHub con tus perfiles reales.
5. Comprueba nombres oficiales de centros, títulos y cualquier detalle antes de publicar.
6. Abre index.html con Live Server para probarlo.

NOTAS
- No se han inventado datos de contacto: los campos que faltan son marcadores para sustituir.
- Los proyectos se presentan como prácticas/documentación, sin afirmar resultados o evidencias que no se hayan indicado.
- Puedes añadir imágenes dentro de multimedia/imagenes y enlazarlas desde HTML con rutas como:
  multimedia/imagenes/mi-ordenador.jpg
